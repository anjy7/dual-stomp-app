About the pedal tuner

Experimental MIDI decoding. Compare with the pedal screen. On/Off preserves other tuner settings; disconnect leaves tuner mode unchanged. The tuner may mute USB audio, so turn it off for lessons.

Setup & troubleshooting
  1. Guitar → Soran → USB → PC. Select Microphone (JME STOMPBOX).
  2. Allow microphone access in Chrome or Edge. Turn off the pedal tuner if it mutes USB audio.
  3. If the level stays flat, check USB routing and Windows microphone permissions. Close competing recording/MIDI apps.
  4. Listen through your pedal/headphones. Live monitoring through PC speakers is disabled.
